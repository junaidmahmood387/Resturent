# Solenne

A portfolio restaurant site for a fictional West Village dining room. Built with Next.js, TypeScript, and Material UI, with a drag-to-rotate 3D plate and a second hearth animation.

## Run it

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` the house, with the 3D plate
- `/menu` à la carte, filters, and dish details
- `/story` the room and the kitchen
- `/gallery` photographs
- `/reserve` a reservation request with validation

The dining room, menu, and guests are fictional. The reservation form does not send data anywhere.
